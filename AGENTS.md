# Sell Mineral Rights Montana — Site-Specific Rules

This project has its own Montana voice and its own Indra Space-derived visual system. Never import a reusable mineral-rights voice pack or reuse another site's hero, FAQ, related rail, article ending, CTA, or decorative language.

## Voice lock

Write as a Montana split-estate record desk. Use township-range descriptions, deed reservations, county instruments, fee minerals, federal and tribal boundaries, paid decimals, spacing records, basin evidence, and a closing ledger. Never use first-person singular business narration, guaranteed value, instant-cash language, or a highest-offer claim.

## Visual lock

Preserve Indra Space's real typography, dark transparent header, violet and orange palette, cinematic video/image hero, asymmetric mosaics, ceramic bands, editorial metrics, alternating image/text sections, functional carousel cadence, and dense footer. Slug pages use one wide hero image, a broad readable article, a Montana record-check FAQ, adjoining-record related links, and a closing-ledger CTA. Never insert a generic rounded card stack.

## Release blockers

- The street address may appear only inside a Google Maps embed query.
- No footer thumbnails, blank images, tiny images, floating media glitches, emoji, or Unicode-arrow decoration.
- Every slug has exactly one image: its hero image.
- No vertical one-character text, squeezed desktop columns, invisible copy, weak contrast, clipped sections, or overlapping header elements.
- Desktop header includes real routes, phone, and a clear contact CTA. Dropdowns work by hover and focus without a pointer gap; the mobile menu and every carousel control work.
- Contact forms contain exactly Name, Email, Phone, and Message.
- Every footer contains a Google Maps embed.
- The homepage hero contains an SEO-driven H1.
- Every page retains the Indra-derived fonts and theme.

Completion requires both machine gates, full desktop/mobile screenshot review, production deployment, and live alias verification.
